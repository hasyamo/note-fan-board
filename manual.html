「観測は続く。」 使い方

昨日、あなたに会いに来た人。
この道具は、その記録を残すためにある。
00
はじめに

「観測は続く。」は、note の スキ・コメント・マガジン追加 を継続的に観測し、誰が来てくれたかを記録するボードです。

noteのダッシュボードでは、スキやコメントの「数」はわかっても、「誰が来てくれたか」までは追いにくい。毎週来てくれてる常連さんも、静かに離れていったファンも、気づかないまま過ぎていきます。

このボードは、その気づかなさに気づくための道具です。

SCOPE
記録と可視化のみ。noteを操作する自動機能はありません。スキ・コメント・マガジン追加は、相手のクリエイターのところへ、自分の足で会いに行ってください。

4タブ構成です。

01
today
Today / 朝、開く
フォロワー推移、昨日のスキ速報、最新記事への反応。一日の最初に、誰が来てくれたかを確認する。
02
fans
Fans / 読みに行く
スキしてくれた人を新規・復帰・常連・たまに・離脱危機に分類。読みに行ってスキ返ししたかも記録できる。
03
ranking
Ranking / 関係を見る
関係の深さでファンランキング。スキだけでなく、コメント・マガジン追加も加点される。
04
magazines
Magazines / 観測する
あなたの記事を、誰がマガジンに追加してくれたかの記録。お礼に行くための導線。
01
Today / 朝、開く
ナビゲーター
陽 / 朝の報告
明るく、誰が来てくれたかを伝えてくれる。

朝、開いて確認するためのタブです。3つのサブタブに分かれています。

概況

フォロワー数の現在値と前日比、過去28日間のフォロワー推移グラフ、もらったスキ数の推移を表示します。

スキ速報

昨日、誰がスキしてくれたか。スキ件数の多い順に並びます。クリックすると、そのクリエイターのページへ遷移できます。

最新記事への反応

あなたの最新記事にスキしてくれた人を一覧で表示。スキ返し・コメント・マガジン追加など、対応が済んだらチェック済みにすることで作業状態を記録できます。

  • 未チェックの人が上、チェック済みは下に薄く表示
  • 並びは、スキしてくれた時刻が古い順
  • チェック状態は端末のブラウザに3日間保存
TIPS
クリエイターページを開いて戻ってくると、「この人への対応は済みましたか？」と確認モーダルが出ます。スキ返しやコメントが終わったら、その場でチェックしてしまうのが楽です。
02
Fans / 読みに行く
ナビゲーター
凛華 / 関係維持・辛口
関係が切れそうな人を、容赦なく突きつける。

スキしてくれた人を5つに分類して表示します。

分類条件
新規今週が初めてスキしてくれた週
常連直近4週のうち3週以上スキしてくれている
復帰過去にスキしたことがあるが、直近4週は一度もなかった人が、今週またスキしてくれた
たまに過去にスキしたことがあり、直近4週のうち1〜2週だけ
離脱危機以前頻繁にスキしてくれていたが、直近4週は一度もない

各カードから直接相手のクリエイターページへ移動できます。スキ返しが済んだら「スキした」を記録できる戻りモーダル付き。

  • 初期表示は50件
  • 下までスクロールすると、自動で次の50件が読み込まれる
  • 全員表示されたら「以上です」
TIPS
スキ返しの記録は、端末のブラウザに保存されます。週が変わるとリセットされ、また「未スキ返し」状態から始まります。
03
Ranking / 関係を見る
ナビゲーター
るな / 感謝・盛り上げ
関係の深い人を一緒に喜んでくれる、親友のような存在。

関係の深さでランキング。スキだけでなく、コメントやマガジン追加も評価されます。

要素加点
スキ（公開1時間以内）×3
スキ（6時間以内）×2
スキ（24時間以内）×1.5
スキ（それ以降）×1
コメント（1件ごと）+3
マガジン追加（1件ごと）+2
2記事以上にスキ（1記事ごと）+0.5

期間は 今週・先週・今月・先月 を切り替えられます。

関係の深さ 💖

カードに 💖1〜5 のバッジが付きます。これは関係の深さを5段階で表したもので、TOP1の人を基準に、相対的に決まります。

スキが0の人はランキングには出ません。コメントやマガジン追加は、スキに加わる加点として効きます。

スクショ用ボタンで、ミニログ等に貼りやすいレイアウトに切り替えられます。画像はご自身でスクリーンショットを撮ってください。

04
Magazines / 観測する
ナビゲーター
日和 / 見守り・広がりを喜ぶ
あなたの記事が誰かのマガジンに迎えられたことを、温かく見届ける。

あなたの記事を、誰かが自分のマガジンに追加してくれた記録です。

あとからゆっくりお礼をしに行けるように、ここに残しています。

表示モード

  • マガジン別: 追加してくれた人をマガジン単位でまとめて表示。カバー画像と運営者アイコンが見られます。
  • 記事別: 自分の記事単位で「どのマガジンに入ったか」を一覧表示。

期間フィルタ

今週 / 先週 / 今月 / 先月 / 全期間 から選べます。自分が運営・参加しているマガジンへの追加は除外されます（他人があなたの記事を気に入って追加してくれたケースのみ）。

導線

  • マガジンへ: そのマガジンページを開く
  • クリエータページへ: 運営者のnoteページを開く（最新記事にお礼コメントする用）

過去に追加された分は、追加日時の代わりに記事の公開日を表示しています。

06
データについて

更新のタイミング

1日に6回、4時間ごとを目安に自動更新しています（5:00 / 9:00 / 13:00 / 17:00 / 21:00 / 1:00 JST 前後）。

運用環境の都合で、実際には数十分〜数時間ずれて反映されることがあります。最後の更新時刻は、ヘッダーの updated: 表示で確認できます。

扱っている情報

このボードで見える情報は、すべて note 上で誰でも見られる公開情報 です。

  • あなたのフォロワー数
  • あなたの記事のスキ・コメント・マガジン追加

note の非公開情報や PV は扱っていません。

07
FAQ
データはどれくらい遅れて反映されますか？
4時間ごとを目安に更新していますが、運用環境の都合で実際には数時間ずれて反映されることもあります。前回の更新時刻はヘッダーの updated: 表示で確認できます。
スキ返しの記録は他の端末でも共有されますか？
されません。記録はブラウザのlocalStorageに保存されるため、端末ごとに独立しています。週が変わると自動でリセットされます。
過去のデータは見られますか？
観測を始めた時点でわかる範囲のスキ・コメント・マガジン追加から表示しています。古い記事のコメントなど、一部の過去分は取れない場合があります。
以降は4時間ごとを目安に、新しい反応を追記していきます。
PWAとしてホーム画面に追加できますか？
できます。iOSのSafariなら共有ボタン → ホーム画面に追加。Androidのブラウザなら「ホーム画面に追加」メニューから。
不具合や要望はどこへ伝えればいいですか？
noteの hasyamo 宛にコメントまたはDMで伝えてください。観測は続いていますが、改善も続けています。
