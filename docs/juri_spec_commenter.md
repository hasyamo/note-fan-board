# ジュリの仕様メモ — コメント常連の定義

## 核心

コメント常連 = 件数が多い人ではない。
**複数の記事に、継続して言葉を置いてくれている人。**

---

## 分類

| 種類         | 条件                              | 意味              |
| ---------- | ------------------------------- | --------------- |
| コメント経験者    | コメント1件以上                        | 一度、言葉を置いてくれた人   |
| コメント反応者    | 直近30日で2コメント以上                   | 最近も反応している人      |
| コメント常連     | 直近30日で3記事以上にコメント               | 継続して関係がある人      |
| 濃いコメント常連   | 直近8週で4週以上コメント                  | かなり安定した関係       |
| 古参コメント常連   | 初コメントから3ヶ月以上、かつ直近もコメント         | 長期的な関係          |

---

## 見るべき指標

```
comment_count          = コメント総数
comment_article_count  = コメントした記事数
comment_week_count     = コメントした週数
last_comment_date      = 最終コメント日
```

件数だけ見るな。Aさん（1記事に10コメント）とBさん（4記事に4コメント）は別物。

---

## MVP実装（ジュリ推奨）

```
コメント常連 = 直近30日で3記事以上にコメント
```

または週単位版：
```
コメント常連 = 直近8週間で3週以上コメント
```

---

## relation_graph での判定

```
commenter:             コメント1件以上
comment_regular:       直近30日で3記事以上にコメント
deep_comment_regular:  直近8週間で4週以上コメント
old_comment_regular:   初コメントから3ヶ月以上 かつ 直近30日で1件以上
```

---

## グラフ上の見せ方

```
コメント常連    → ノードにリング
濃いコメント常連 → リングを二重
```

サイズだけだと「単発大量コメント」と区別できない。
