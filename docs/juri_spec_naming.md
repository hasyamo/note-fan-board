# ジュリの仕様メモ — 命名・ラベル設計

## 名称の使い分け

| 用途 | 名称 |
|---|---|
| 画面タイトル（UI） | READER MAP |
| 記事・メンシプ説明 | READER MAP｜読者との足あとマップ |
| 機能説明文 | note記事に残ったスキやコメントをもとに、読者との関係の足あとを可視化するマップです。読者を格付けするものではなく、どの時期に、どんな反応が集まっていたのかを振り返るためのツールです。 |
| 記事タイトル案 | 読者との足あとを3Dマップにしてみた｜READER MAP |

## ラベルの使い分け

| utype | はしゃも本人用 | メンシプ配布版 |
|---|---|---|
| core | 濃いファン | よく反応してくれる人 |
| commenter | コメント常連 | コメント常連 |
| active_commenter | コメントあり | コメントをくれた人 |
| regular | 定期読者 | 継続して読んでくれる人 |
| newcomer | 新規読者 | 最近来てくれた人 |
| dormant | 休眠読者 | しばらく静かな人 |
| active | スキ読者 | スキで反応してくれる人 |

月フィルター時：
| monthly_utype | はしゃも本人用 | メンシプ配布版 |
|---|---|---|
| monthly_core | 今月：濃い | 今月：反応多め |
| monthly_commenter | 今月：コメント | 今月：コメント |
| monthly_active | 今月：スキ | 今月：スキ |

## その他の修正候補

- 「読者数」→「観測読者数」（スキ1件以上を含むため、全員が読者とは限らない）
- 内部コード（utype）は変更不要、画面表示ラベルだけ変える

## 名称候補メモ

- READER MAP（採用）
- READER TRACE（足あと感あり、UIに合う）
- READER ORBIT（世界観あり、詩的すぎる）
- READER RELATION MAP（正確だが長い）
